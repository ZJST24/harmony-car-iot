## 5. 今天踩过的坑（下次别重犯）

| # | 现象 | 根因 | 解法 |
|---|---|---|---|
| 1 | `ModuleNotFoundError: No module named 'paho'` | 裸 `python` 是 3.13，依赖装在 3.10 | 一律用 `D:\miniconda\python.exe`；README 里的 `D:\anaconda3\` 在你这台机器上不存在 |
| 2 | 担心脚本挑错密钥文件 | 根目录有两份同名 `mycar_001` | 001 里加 `KEY_FILE_NAME` 常量显式指定文件名 |
| 3 | MQTT rc=4 鉴权失败 | 时间戳写成北京时间 / HMAC 参数顺序反 | 时间戳必须 **UTC**；`HMAC(密钥=timestamp, 内容=secret)` |
| 4 | 后端恒定 `403 IOTDA.000021` | 三处叠加：通用端点、缺衍生签名、多带 `instance_id` | 专属端点 + `with_derived_predicate` + **不带** `instance_id`；`test_api_auth.py` 可一键体检 |
| 5 | APP 六项指标全是 `--` | **ArkUI `@Builder` 按值传参只在创建时求值，状态变了不刷新** | 改成 `@Component + @Prop`；`@Builder` 只用于参数恒定的静态片段 |
| 6 | 网页发 POST 被浏览器拦 | 只给了 `Allow-Origin`，JSON 触发 OPTIONS 预检 | 补 `Allow-Headers: Content-Type`，并把页面挂到后端同源托管 |
| 7 | `hvigorw` 只出 unsigned HAP | CLI 没有签名配置 | DevEco → Project Structure → Signing Configs 勾自动签名 |
| 8 | 免费额度焦虑 | S0 每天 1 万条消息 | 车端 运动 5s/静止 60s 上报；APP 轮询别低于 2s |

**还有一个不是坑但容易误判的现象**：影子数据 5s/60s 才刷新一次，STOP 之后立刻查 `/status`，`speed` 可能还是旧值，下个上报周期才归零。

## 12. 控制台多车同屏（2026-11-08 17:12）

**一句话**：不用再手动切换看车，画布上**同时显示台账里所有在线车辆**；但方向键、紧急停车、语音指令仍然**只作用于「当前控制」那一台**，不会广播。

### 为什么顺带加了后端接口

多车同屏如果让前端对每台车各发一次 `/status`，N 台车 = N 个 HTTP + 2N 次云 API，2 秒轮询很快打满。所以新增 `GET /fleet_status`：服务端 `ThreadPoolExecutor` 并发查全部 `enabled` 车辆，1 秒短缓存让多页面 / 多次轮询共用快照，单台查询失败只影响该车自己的 `ok=false`。**现有五个接口的入参出参一字未改。**

### 改了什么

| 文件 | 变化 |
|---|---|
| `server/app.py` | 新增 `GET /fleet_status`（I-17）；并发查询 + 缓存 + 单台容错；启动横幅加一行 |
| `web/car_console.html` | 状态从单车变量重构为 `fleet[]`：每车独立影子 / 航位推算 / 轨迹 / 专属色 / 在线状态；画布同屏绘制 + 名字标签 + 选中车虚线光环；HUD 下方新增「车队概览」卡片；点击画布上的车、卡片或右上角下拉切换控制对象；右上角徽标改为 `2/2 台在线 · 当前控制：1 号车` |

### 三条必须记住的设计取舍

1. **切换控制对象不再清空任何车的状态**——这正是「同屏」和「切换查看」的本质区别；第 11 节里"换车清空航位推算与轨迹"那条已废止。

## 14. M2 绑定授权（2026-11-08 17:48）

### 为什么这一步不能只做「选车 UI」

用户↔车的关联**不是界面功能，是授权边界**。前端把按钮灰掉没用，服务端必须在每次下发前重新校验 `(身份, device_id)`。所以 M2 的落点是「身份台账 + 请求级鉴权 + 写接口逐次裁决 + 审计」，UI 只负责把结果如实展示。

### 改了什么

| 文件 | 变化 |
|---|---|
| `server/access.json` | **新增**。4 个演示身份 + 匿名访客；user / token / role / `devices`（可控制）/ `scope`（可见）/ enabled。**token 只存后端**，与 `config.json` 的 AK/SK 分开；按文件 mtime 热加载 |
| `server/access_admin.py` | **新增**。绑定关系维护 CLI：`list` / `grant` / `revoke` / `rotate` / `enable` / `disable` / `scope` / `strict`；原子替换写文件，改完下一请求生效 |
| `server/app.py` | `before_request` 解析身份（`X-Auth-Token` / `Authorization: Bearer` / `?token=`）、`can_view` / `can_control`、`guard_view` / `guard_control`；新增 `GET /whoami`；`/devices`、`/fleet_status` 按可见范围裁剪并带 `can_control`；`/command`、`/voice_command` 下发前逐次校验；`dispatch()` 与审计日志带 `user=`；CORS 放行新 header；启动横幅打印鉴权状态 |
| `web/car_console.html` | 新增「身份与授权」卡片（令牌输入 / 应用 / 退出 / 身份徽标），`apiFetch()` 统一自动带 header；无控制权的车标「只读 · 无控制权」、cmdState 预告 403；越权如实显示并写指令记录；语音链路错误映射新增 `auth` |
| `web/car_cloud_view.html` | 同源复用 `localStorage.carAuthToken`，右上角显示身份；保持严格只读（无输入框、无控制按钮）；401/403 不误显示成「后端不通」 |
| 鸿蒙 `CarApi.ets` | 新增 `getDevices` / `whoami`；`getStatus` / `sendCommand` 增加 token 与 `device_id` 参数，请求头带 `X-Auth-Token` |
| 鸿蒙 `Index.ets` | `PersistentStorage` 持久化 authToken / deviceId；新增身份栏 + 选车按钮行 + 设置面板令牌输入；默认落在「当前身份可控制」的车上；旧后端 404 退回单车模式 |
| `docs/接口文档.md` | 升 v1.5：新增 I-18 `/whoami`、「鉴权约定」全表、I-16 与第 8 节更新 |

### 关键设计：可见 ≠ 可控

为的是不让刚做好的「多车同屏」退化。默认 `scope=all`，任何身份都能**看见**全部车；但只有 `devices` 命中的车能**下发**。所以访客态仍是两车同屏，切到 2 号车只看到「只读」，点方向键被服务端 403 拦下。若把某账号 `scope` 设成 `bound`，则连 `/devices`、`/fleet_status`、`/status` 都会按绑定裁剪。

### 课堂演示怎么走

1. 控制台顶部「身份与授权」粘贴教师/分组令牌 → 点「应用」（先打 `/whoami` 校验）。令牌存在浏览器 localStorage，刷新不丢。
2. 访客态：控 1 号车正常，控 2 号车 → 403 且 `commands.log` 留下「越权拒绝」。
3. `D:\miniconda\python.exe access_admin.py grant group1 <002的device_id>` → **不重启后端**，group1 下一请求立刻能控 2 号车；`revoke` 后立刻又被拦。
4. `access_admin.py strict on` → 严格模式，不带 token 一律 401（演示完记得 `strict off`）。
5. 观察员身份：能看到两车，但点任何按钮都 403。

### 实测（17:48，线上 8000）

```
/whoami 访客             -> 可控 1 / 可见 2
/devices                 -> 1 号车 can_control=true、2 号车 false
/fleet_status            -> 2 台（可见全量，不退化）
POST /command 002 访客   -> 403 stage=auth，审计「越权拒绝 -> user=guest」
POST /command 001 访客   -> 200 executed=true
POST /command 002 教师   -> 200 executed=true
无效 token               -> 401 stage=auth
/voice_command 002 访客  -> 403 stage=auth（仅解析也要过控制权）
strict on 时无 token     -> /whoami 与 /devices 均 401
旧接口 /health /status   -> 200，行为不变
DevEco hvigor assembleHap -> BUILD SUCCESSFUL（CompileArkTS 通过，unsigned HAP）
```

### 兼容与边界

- `require_token=false`（默认）：不带 token 视为访客，**旧 APP / 旧 curl 零改动**；只有默认车可控制。
- 严格模式、伪造 token、停用账号分别返回 401 / 401 / 403，都带 `stage=auth`。
- token 用 `hmac.compare_digest` 常量时间比较、绝不进日志；`/whoami` 不返回 token。
- 静态页面 `/`、`/view`、`/console` 仍公开（身份在页面里输入），接口才鉴权。

## 15. M3 场地坐标映射 + 任务级指令编排（2026-11-08 18:10）

**为什么这么切**：原先画面里的 `(x, y)` 只是「像素」，车在哪里、跑了多远、能不能进某个区域都说不清；命令也只能一次点一下。M3 分两层解决：

- **坐标层**：给逻辑坐标加上物理含义（米制 + 区域 + 安全边界），并把底图做成**本地自绘矢量场地**。
- **编排层**：把多条规范指令编成一个任务，逐步下发、逐步等回执、可观测、可急停。

### 为什么不直接接在线地图

合规是硬约束：默认不加载任何在线瓦片、不绘制国界/行政区划，断网也能演示。真实地理底图单独放在 `/map`，只用腾讯位置服务 GL JS 官方 **key 代理模式**（SDK URL 不带 key、页面零密钥、GCJ-02）；允许清单仅腾讯位置服务 / 高德 / 百度 / 天地图，禁止 Google Maps、Apple Maps、Bing 海外版、OSM 境外瓦片、Mapbox、Leaflet+OSM。

`field.json` 里的 `geo` 默认 `enabled=false / calibrated=false / 原点 (0,0)`，**未校准时后端一律不输出经纬度**（`/field` 把原点抹成 `null`，`/status` 与 `/fleet_status` 的 `pos.geo=null`），`/map` 也不打点——避免把示例原点误当成真实位置。要启用必须现场用合规服务商采集 GCJ-02 基准点，在管理台填好并勾「已现场校准」。

### 坐标约定

| 层 | 定义 |
|---|---|
| 逻辑坐标 | 左上 (0,0)，x 向右 / y 向下，800×600，与车端影子上报一致 |
| 场地米制 | `east = x × meters_per_unit`、`north = -y × meters_per_unit`（默认 0.025 m/单位 ⇒ 20 m × 15 m） |
| 地理坐标 | 米制坐标按 `rotation_deg` 旋转后，用局部平面近似换算成 GCJ-02 经纬度；仅在已校准时输出 |

`server/field_map.py` 与 `web/field.js` 是同一套公式（实测 `(400,300)` → 东 10.00 m / 北 -7.50 m，两端一致）。底图元素：`zones`（待命区 / 禁行区 / 巡检主通道 / 充电位）、`geofence`（多边形 + 内缩 20）、`waypoints`（P1~P3）、米制网格与比例尺。

### 任务状态机

`server/mission.py`，4 个预设：`square` 矩形巡检 / `out_back` 直线往返 / `patrol` 通道巡检 / `selfcheck` 原地自检。状态 `pending → running → succeeded | failed | cancelled`，每步记 `results[]`（命令、参数、command_id、executed、耗时），每步后采样 `trail[]`（含 `pos`），事件追加写 `missions.log`。

**五条安全约束（比功能更重要）**

1. 同一台车同时只允许一个进行中任务，第二个请求 400「避免两个任务抢方向盘」。
2. 每一步下发前**重新读 access.json** 复检 `(身份, device_id)`：任务跑一半被 revoke / 停用账号立即 `failed`。
3. 只认五条白名单指令，**AI 自然语言不进这条链**；speed 0~100、单步 100~5000 ms、≤20 步、总时长 ≤60 s。
4. 启动前车辆必须在 geofence 内，越界拒绝启动；急停不受此限制。
5. 成功/失败都自动发 STOP 收尾；取消立即异步发 STOP；物理/直连急停入口不变。

### 新增接口与页面

`GET /field`、`GET /mission/presets`、`POST /mission`、`GET /missions`、`GET /mission/<id>`、`POST /mission/<id>/cancel`、`POST /mission/abort_all`；`GET /map`（合规地理底图）、`GET /field.js`（前端映射库）。控制台新增「任务级指令编排」卡片与场地坐标 HUD/卡片；`/view` 叠加同一套底图并显示**只读**任务进度；旧后端没有 `/field` 时自动退回原 50px 网格，控车不退化。

### 课堂演示怎么走

1. 打开 `/`：画面变成带米制网格、禁行区、安全边界、巡检点的场地；HUD 多一行「场地坐标（m / 区域）」。
2. 选 `原地自检` → 「启动任务」：任务卡片出现进度条，每步一条 `executed=true` 回执，结束自动停车。
3. 启动一个长任务 → 立刻「取消并急停」：状态变 `cancelled`，`commands.log` 里能看到 STOP。
4. 用管理台把车辆绑定关系在任务运行中改掉，观察任务下一步立刻 `failed`（逐步授权复检）。
5. 打开 `/map`：未标定时如实提示；标定后在 WorkBuddy 预览面板里能看到 GCJ-02 打点与轨迹。

## 16. M4 B/S 管理台（2026-11-08 18:10）

**定位**：把 M2 只能靠 `access_admin.py` 命令行维护的绑定关系、严格模式、设备台账搬进 Web；顺手把 M3 的场地标定、任务监控、审计日志也收进同一个后台。

### 鉴权边界（不是界面功能）

`/admin` 页面本身公开（令牌在页内输入并存 `sessionStorage`），但 `/api/admin/*` **每个请求**都要求 `role=admin` 的有效令牌；`access.json enabled=false` 时管理台整体停用（否则人人都是 guest，等于没有管理员）。用户列表只回 token 掩码，完整令牌仅在「新建 / 轮换」的当次响应里出现一次。不能停用/降权/删除当前登录管理员，也不能删掉最后一个 admin。

### 接口清单

`GET /api/admin/overview | users | devices | field | audit | missions`、`POST /api/admin/users | strict | abort_all`、`POST /api/admin/users/<u>/rotate`、`POST /api/admin/missions/<id>/cancel`、`PATCH /api/admin/users/<u> | devices/<id> | field`、`DELETE /api/admin/users/<u>`。详见 `docs/接口文档.md` I-21。

### 写操作怎么保证不把台账写坏

所有写操作用 `json.dump → os.replace` 原子替换（后端不会读到半个文件），写 `[ADMIN]` 审计；`access.json` / `field.json` 按 mtime 热加载，`devices.json` 改完强制 `sync_devices(force=True)` 原地刷新 `DEVICE_LIST / DEVICE_MAP / DEFAULT_DEVICE`——**管理台改完下一请求立即生效，不用重启 app.py**。CLI `access_admin.py` 仍可用，改的是同一份文件。

### 课堂演示怎么走

1. 浏览器打开 `http://127.0.0.1:8000/admin`，粘贴 `teacher` 令牌 → 「进入管理台」。
2. 账号表勾掉 `group2` 对 2 号车的绑定 → 到控制台用 group2 令牌控 2 号车 → 403；勾回来 → 立刻能控（不重启）。
3. 设备表把 2 号车「启用」取消 → `/devices` 立刻少一台。
4. 开「严格模式」→ 不带令牌的 `/whoami` 变 401；确认 APP/控制台已配令牌后再演示，演示完关掉。
5. 任务监控里点「取消 / 急停」或「一键全停」；审计日志能看到 `[ADMIN]` 与 `越权拒绝` 记录。
6. 场地标定改 `1 单位 = 0.05 m` → 控制台 HUD 的米制坐标立刻翻倍（热加载）。
